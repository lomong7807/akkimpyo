## 1. 색

### 1.1 테마 적용 (설계서 2.1)

화면은 기본으로 기기 설정(`prefers-color-scheme`)을 따라 밝은 화면과 어두운 화면 중 하나로 보인다. 사용자는 화면 설정(M-03)에서 "시스템 따름"(기본), "밝게", "어둡게"를 고를 수 있고, 고른 값은 그 기기에만 저장된다(F-902).

- 시스템 따름: 문서 루트(`<html>`)에 `data-theme`을 두지 않는다. 기기 설정이 어두우면 어두운 화면 값을 쓴다.
- 수동 지정: 문서 루트에 `data-theme="light"` 또는 `data-theme="dark"`를 둔다. 이 값이 기기 설정보다 앞선다.
- 고른 테마는 화면을 처음 그리기 전에 적용한다. 기기에 저장한 값을 `<head>` 안에서 읽어 `data-theme`을 단다. 시스템 따름 상태에서 앱을 연 채 기기 설정이 바뀌면 바로 따라 바뀐다.

```css
:root { /* 밝은 화면 값 */ }
@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) { /* 어두운 화면 값 */ }
}
:root[data-theme="dark"] { /* 어두운 화면 값 */ }
```

## 8. 아이콘, 움직임, 그래프, 초점, 층, 안전 영역 (설계서 2.6)

| 항목 | 규칙 |
|------|------|
| 아이콘 | Phosphor 한 종류만 쓰고 굵기는 Regular로 통일한다. 고른 탭도 굵기를 바꾸지 않고 색만 바꾼다. 이모지는 쓰지 않는다. 글자 없이 아이콘만 있는 버튼에는 접근성 이름(`aria-label`)을 단다. 크기는 24px과 20px 두 가지다(6절) |
| 움직임: 시트 종류 | 바닥 시트, 펼친 판, 가운데 창, 전체 화면 입력이 나타나고 사라질 때 200ms, `cubic-bezier(0.2, 0, 0, 1)` |
| 움직임: 누름 | 누를 때 100ms 동안 `transform: scale(0.98)` |
| 움직임: 토스트 | 150ms 동안 투명도만 바뀐다 |
| 움직임 줄이기 | `prefers-reduced-motion: reduce`이면 위 움직임을 모두 끄고 바로 나타나고 바로 사라지게 한다 |
| 쓰지 않는 움직임 | 반복되는 장식 애니메이션, 숫자가 올라가는 효과, 뼈대의 번쩍임(shimmer). 뼈대는 멈춘 회색 막대다 |
| 그래프 | 막대만 쓴다. 원 그래프와 선 그래프는 쓰지 않는다. 지출 막대는 `color-text-secondary`, 수입 막대는 `color-accent`, 예산 초과분은 `color-danger`, 막대의 남은 칸(바탕)은 `color-border`다. 막대 옆에는 금액 글자를 늘 함께 둔다 |
| 키보드 초점 | 2px `color-accent` 테두리를 요소 바깥으로 2px 띄워 그린다. 마우스나 손가락으로 누를 때는 보이지 않게 `:focus-visible`로 건다 |
| 층 순서(아래에서 위로) | 내용, 상단 바·하단 탭·사이드바·연결 없음 띠, 빠른 입력 버튼, 가림막과 바닥 시트·가운데 창·펼친 판·전체 화면 입력, 토스트 |
| 안전 영역 | 상단 바와 하단 탭은 `env(safe-area-inset-top)`, `env(safe-area-inset-bottom)`만큼 안쪽 여백을 더한다(iPhone 홈 화면 웹앱, F-120). 브라우저 위쪽 색(`theme-color`)은 지금 적용된 테마의 `color-bg`에 맞추고, 테마가 바뀌면 함께 바꾼다 |

- 움직임 값의 변수 이름은 frontend가 tokens.css PR에서 제안하고 designer가 확인한다.

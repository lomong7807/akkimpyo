## 1. 모든 컴포넌트에 공통인 규칙

아래 표의 상태는 컴포넌트를 만들 때 함께 만든다. 화면에서 컴포넌트 모양을 덮어쓰지 않는다([README](README.md) 5절). 2절부터의 "상태" 열은 이 표와 다른 점만 적는다.

| 항목 | 규칙 | 절 |
|------|------|----|
| 터치 영역 | 44 x 44px 이상 | 2.4 |
| 눌림 | 100ms 동안 `transform: scale(0.98)`. 누를 수 있는 줄(목록 줄, 메뉴 줄, 시트의 고르는 줄)은 `color-press` 바탕 | 2.6, owner 결정 2 |
| 마우스 올림 | 누를 수 있는 줄과 아이콘 버튼은 `color-press` 바탕. 그 밖은 정의 없음 | owner 결정 2 |
| 키보드 초점 | 2px `color-accent` 테두리를 요소 바깥으로 2px 띄워 그린다. `:focus-visible`로 건다 | 2.6 |
| 비활성 | 버튼은 `color-border` 바탕, `color-text-secondary` 글자, `aria-disabled="true"`. 글자 버튼은 글자만 `color-text-secondary`. 쓰는 곳은 처리 중, 연결이 없을 때 서버가 필요한 버튼, 기능정의서가 비활성으로 정한 버튼 세 가지뿐이다 | 5.1, 4.3, 4.4 |
| 처리 중 | 누른 버튼을 비활성으로 바꾸고 글자 자리에 돌아가는 원 20px. 버튼 폭은 그대로, 두 번 눌리지 않는다. 입력 화면이면 칸도 바꿀 수 없다. `aria-busy="true"` | 4.5 |
| 권한 없음 | 버튼을 숨긴다. 흐리게 두지 않는다 | 4.5, 5.1 |
| 움직임 줄이기 | `prefers-reduced-motion: reduce`이면 움직임을 모두 끈다 | 2.6 |

## 3. 버튼

| 종류 | 모양 | 크기, 터치 영역 | 쓰는 곳 | 절 |
|------|------|-----------------|---------|----|
| 주 버튼 | `color-accent` 바탕, `color-on-accent` 글자(`text-body-strong`), 모서리 10px | 높이 48px | 화면마다 하나. 입력 화면의 저장 버튼은 화면 맨 아래에 고정하고 좌우 16px 여백을 둔 전체 폭 | 5.1 |
| 위험 버튼 | `color-danger` 바탕, `color-on-danger` 글자, 모서리 10px | 주 버튼과 같다(높이 48px) | 확인 창 안에서 지우거나 없애는 동작의 실행 버튼 | 5.1 |
| 보조 버튼 | `color-surface` 바탕, 1px `color-border-strong` 테두리(owner 결정 6), `color-text` 글자, 모서리 10px | 높이 44px | 주 버튼 말고 버튼이 더 필요할 때, 확인 창의 "닫기" | 5.1 |
| 글자 버튼 | 바탕과 테두리 없음, `color-accent` 글자. 지우거나 없애는 동작이면 `color-danger` 글자 | 누르는 영역 44px | 줄 안의 동작, "다시 시도", 링크 | 5.1 |
| 아이콘 버튼 | 아이콘 24px, `aria-label` 필수 | 누르는 영역 44 x 44px | 닫기(X), 뒤로(CaretLeft), 이전·다음 달(CaretLeft, CaretRight) | 5.1 |

- 버튼 글자는 `text-body-strong`이다(2.3의 쓰임 "버튼 글자").
- 버튼 글자는 한 줄이다. 두 버튼이 한 줄에 들어가지 않으면 위아래로 쌓고 실행 버튼을 위에 둔다.
- 화면 맨 아래에 따로 떼어 두는 되돌릴 수 없는 동작은 화면에서는 위험색 글자 버튼이고, 누르면 확인 창의 위험 버튼으로 실행한다(한 화면의 주 버튼은 하나).
- 비활성 규칙: 1절 표의 "비활성". 쓰는 곳은 세 가지뿐이고, 권한이 없는 버튼은 비활성이 아니라 숨긴다. 비활성인 동안 이유를 버튼 바로 위에 한 줄(`text-caption`, `color-text-secondary`)로 보인다(4.4). 연결 없음 때문이면 4.3을 따른다(띠가 보이면 문구 없음, 띠가 보이지 않는 곳에서는 "연결되면 ~할 수 있어요").
- 아이콘 버튼에 마우스를 올리면 `color-press` 바탕이다(owner 결정 2). 바탕의 모양은 10절 C-3.

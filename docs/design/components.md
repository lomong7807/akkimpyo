## 1. 모든 컴포넌트에 공통인 규칙

아래 표의 상태는 컴포넌트를 만들 때 함께 만든다. 화면에서 컴포넌트 모양을 덮어쓰지 않는다([README](README.md) 5절). 2절부터의 "상태" 열은 이 표와 다른 점만 적는다.

| 항목 | 규칙 | 절 |
|------|------|----|
| 터치 영역 | 44 x 44px 이상 | 2.4 |
| 눌림 | 100ms 동안 `transform: scale(0.98)`. 누를 수 있는 줄(목록 줄, 메뉴 줄, 시트의 고르는 줄)은 `color-press` 바탕. 유형 고르기는 축소 없이 고르지 않은 칸의 `color-press` 바탕이다(4절) (#102, #85) | 2.6, owner 결정 2 |
| 마우스 올림 | 누를 수 있는 줄과 아이콘 버튼은 `color-press` 바탕. 아이콘 버튼의 바탕은 44x44px에 모서리 10px이다 (#102, #77). 달력의 날짜도 같다(5.8). 손가락으로 누른 뒤 바탕이 남지 않게 `@media (hover: hover)`에서만 건다 (PR #138의 designer 검토). 그 밖은 정의 없음 | owner 결정 2 |
| 키보드 초점 | 2px `color-accent` 테두리를 요소 바깥으로 2px 띄워 그린다. `:focus-visible`로 건다. 예외는 아래 "초점의 예외" 줄 | 2.6 |
| 초점의 예외 | 입력칸 모양의 칸(입력칸, 금액·날짜·시각·고르는 칸, 검색, 메모)은 안쪽 2px 테두리 하나로 초점을 보이고 바깥 테두리는 투명하게 둔다(5.2) (#102, #78, PR #162). 유형 고르기, 스위치, 선택 원, 확인란, 칩, 버튼은 바깥 테두리다 (#102, PR #162). 고대비 모드에서는 투명한 바깥 테두리가 2px로 보이는 것이 맞다 (#102, PR #162). 화면 끝까지 닿는 목록 줄은 바깥이 잘리므로 안쪽(-2px)에 그린다 (#102, #81). 달력의 날짜는 안쪽에 그린다(2.6, 5.8) | 2.6, 5.2, 5.8 |
| 비활성 | 버튼은 `color-border` 바탕, `color-text-secondary` 글자, `aria-disabled="true"`. 글자 버튼은 글자만 `color-text-secondary`. 쓰는 곳은 처리 중, 연결이 없을 때 서버가 필요한 버튼, 기능정의서가 비활성으로 정한 버튼 세 가지뿐이다 | 5.1, 4.3, 4.4 |
| 처리 중 | 누른 버튼을 비활성으로 바꾸고 글자 자리에 돌아가는 원 20px. 버튼 폭은 그대로, 두 번 눌리지 않는다. 입력 화면이면 칸도 바꿀 수 없다. `aria-busy="true"`. 원은 800ms(`--motion-spinner-duration`)에 한 바퀴 돌고 움직임 줄이기에서도 돈다 (#102, #77). 처리 중인 입력칸은 모양을 바꾸지 않는다(비활성 색으로 바꾸면 짧게 깜빡인다) (#102, #78) | 4.5 |
| 다시 보내는 동안 | "다시 시도"로 다시 보내는 동안 실패 문구는 남기고 누른 버튼만 처리 중 표시를 둔다. 로그인, 가입, 첫 실행 안내, 계좌 추가, 거래 입력, 거래 상세의 창이 모두 같다 (#102, #88). 로그인의 거부 문구("이메일 또는 비밀번호가 맞지 않아요")도 새 결과가 올 때까지 남긴다 (#102, #224, PR #227) | 4.3 |
| 실패 뒤 초점 | 실패하면 초점을 "다시 시도"로 옮기는 곳은 아래 고정 영역을 키보드 위로 올리지 않는 입력 화면(A-03, A-06, C-02)뿐이다. 서버 오류, 응답 지연, 연결 끊김처럼 "다시 시도"가 나오는 모든 실패에서 같다. 로그인(A-02), 계좌 추가(G-02), 거래 입력(D-04)은 초점을 옮기지 않는다 (#102, PR #180, PR #195, #83, #86) | 4.3 |
| 누르기 막기 | 시트와 판을 막 열거나 닫은 뒤 300ms 동안 손가락과 마우스를 받지 않는다. 달력과 X도 함께 막는다. Esc와 키보드는 바로 받고, 움직임 줄이기에서도 같다. 값은 `web/src/components/pressGuard.ts`의 `PRESS_GUARD_MS`다 (#102, #83). 첫 실행 안내를 떠날 때도 같은 300ms 덮개를 둔다 (#102, #84). 설계서 5.4는 아직 앞선 결정인 "열리는 200ms 동안"이다(10절 C-11) | 5.4 |
| 권한 없음 | 버튼을 숨긴다. 흐리게 두지 않는다 | 4.5, 5.1 |
| 움직임 줄이기 | `prefers-reduced-motion: reduce`이면 움직임을 모두 끈다. 버튼의 처리 중 원은 예외로 돈다 (#102, #77) | 2.6 |
| 문구 | 마침표는 00-common 3.1을 따른다 (#102, PR #204). 화면 읽기에만 알리는 글은 마침표를 찍고, 화면에 보이는 같은 뜻의 한 문장 글은 찍지 않고 따로 둔다(예: 로딩의 "불러오고 있어요") (#102, #206). 같은 뜻은 어디서나 같은 모양과 같은 말로 쓴다 (#102, PR #180). 화면 글에 "서버"라는 말을 쓰지 않는다 (#102, #236, #239) | 3.1, 3.3 |

- 버튼 글자는 `text-body-strong`이다(2.3의 쓰임 "버튼 글자").
- 버튼 안쪽 좌우 여백은 주 버튼과 위험 버튼 24px, 보조 버튼 16px, 글자 버튼 8px이다 (#102, #77).
- 확인 창의 두 버튼은 보조 버튼("닫기")도 높이 48px이다(6절 확인 창) (#102, #83).
- 오류 문구와 그 아래 "다시 시도" 사이는 4px이다. 초점 테두리가 글자와 겹치지 않게 하기 위해서다 (#102, #80).
- "이미 계정이 있나요? 로그인"처럼 글과 링크가 한 줄인 곳은 줄이 바뀌면 왼쪽을 맞춘다 (#102, #80).
- 버튼 글자는 한 줄이다. 두 버튼이 한 줄에 들어가지 않으면 위아래로 쌓고 실행 버튼을 위에 둔다.
- 화면 맨 아래에 따로 떼어 두는 되돌릴 수 없는 동작은 화면에서는 위험색 글자 버튼이고, 누르면 확인 창의 위험 버튼으로 실행한다(한 화면의 주 버튼은 하나).
- 비활성 규칙: 1절 표의 "비활성". 쓰는 곳은 세 가지뿐이고, 권한이 없는 버튼은 비활성이 아니라 숨긴다. 비활성인 동안 이유를 버튼 바로 위에 한 줄(`text-caption`, `color-text-secondary`)로 보인다(4.4). 연결 없음 때문이면 4.3을 따른다(띠가 보이면 문구 없음, 띠가 보이지 않는 곳에서는 "연결되면 ~할 수 있어요").
- 아이콘 버튼에 마우스를 올리면 `color-press` 바탕이다(owner 결정 2). 바탕은 44x44px에 모서리 10px이다(10절 C-3) (#102, #77).

버튼 이름 규칙:

- 기본은 00-common 3.1이다: 동사로, 되도록 3단어 이하, 한 줄. 확인 창의 실행 버튼은 동작 이름이고 물러나는 버튼은 "닫기"다(5.6).
- 누르면 무엇이 나오는지 알 수 있는 이름을 쓴다. "선택하기"처럼 다음 일을 알 수 없는 이름은 쓰지 않는다(예: "비교해서 고르기") (#102, #280).
- 누를 수 없는 줄이나 글자에는 "목록 보기" 같은 동작 이름을 붙이지 않는다 (#102, #235).
- 같은 화면에 같은 일을 하는 버튼이 둘이면 접근성 이름으로 구분한다. 보기 버튼은 "{칸 이름} 보기", 누르면 "{칸 이름} 숨기기"다(01 A-02 (3)) (#102, #213).
- 같은 선택의 결과는 화면이 달라도 같은 말로 알린다(예: "저장된 내용으로 두었어요") (#102, #239, #280).

## 11. 앱 아이콘

홈 화면에 설치할 때의 아이콘과 브라우저 탭의 파비콘이다. 원본 그림은 [assets/](assets/)에 있다 (#102, #91).

| 항목 | 정의 |
|------|------|
| 모양 | 강조색 바탕(`color-accent` 밝은 값 `#0F7B5F`)에 흰 글자(`#FFFFFF`) "아" 한 자. 글꼴은 Pretendard, 굵기 700. 장식, 테두리, 그림자, 그라데이션은 없다 |
| 홈 화면 아이콘 | [assets/icon-A.png](assets/icon-A.png). 1024 x 1024px 판의 가운데에 글자 크기 540px, 글자를 위로 8px 올렸다 |
| 파비콘 | [assets/favicon-A.png](assets/favicon-A.png). 같은 그림에서 글자만 키운 판이다. 1024 x 1024px 판에 글자 크기 760px, 위로 12px. 작은 크기에서도 글자가 읽히게 하기 위해서다 |
| 판의 모서리 | 원본 그림은 모서리가 없는 네모다 |

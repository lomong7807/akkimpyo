## 0. 이 문서에서 더 정한 표기

- 한 화면을 상태별로 나눠 그릴 때 요소 번호는 그 화면 안에서 이어서 매긴다. 같은 번호는 어느 그림에서나 같은 요소다. 각 그림 아래 요소 표에는 그 그림에서 처음 나온 요소만 적는다.
- 그림 안의 `{상단 바}`, `{하단 탭}`, `{사이드바}` 는 공통 틀(00-common.md 3절)이다. 번호를 매기지 않는다.
- 그림은 편집 이상 권한의 사용자가 보는 화면으로 그렸다. 뒤 단계 요소(`[2]`, `[3]`)도 모두 그림에 넣었다. 단계 표시는 요소 표의 요소 이름 뒤에 붙인다.
- 보기 전용 구성원에게는 편집 동작의 버튼(수정, 삭제, 확인 등)과 빠른 입력 버튼이 보이지 않는다(00-common.md 4절 8번). 빠른 입력 버튼은 그림에서 생략했고, 보이는 범위는 00-common.md 3.1을 따른다.
- 예시 값은 김도윤(P1)의 "내 가계부"를 기본으로 쓰고, 여러 사람이 필요한 화면은 박준호와 최하은(P3)의 "데이트 장부", 정민서(P4)의 "여행 모임" 장부를 쓴다.

### D-04 거래 입력·수정 [1]

들어오는 길: 어느 화면에서든 빠른 입력 버튼(B-03)을 누른다(지출로 열린다). 거래 상세(D-06)의 "수정", 한 줄 입력 결과 확인(D-05)의 "자세히", 미확인 검토 목록(D-09)의 "고치기", 보내지 않은 입력 목록(B-05)의 "고쳐서 보내기"로도 온다.

아래에서 올라오는 전체 화면이다. 하단 탭과 빠른 입력 버튼이 없다. 필수 항목(금액, 계좌, 날짜)은 위쪽에 있고 기본값이 채워져 있어 금액만 넣고 저장할 수 있다. 선택 항목은 "더 보기" 아래에 접혀 있다. 아래 그림은 상태별로 나눠 그렸다.

## E. 통계

E 그룹 여섯 화면은 모두 맨 위에 같은 통계 전환 줄(F-311)을 둔다. 전환 줄은 월 통계(월별 E-01, 카테고리 E-02, 사람별 E-03 `[2]`, 예산 E-04 `[3]`)와 연 통계(연 단위 E-05, 회비 E-06 `[2]`) 두 묶음으로 나뉜다. 지금 화면의 이름이 강조된다. 단계가 오지 않은 칸은 보이지 않고, 사람별은 구성원이 2명 이상인 장부에서만 보인다.

기간은 화면을 옮겨도 이어진다(F-311). 월 통계 화면 사이를 옮길 때는 고른 달이 그대로이고, 연 통계 화면으로 가면 고른 달이 속한 연도가 선택되며, 연 통계에서 월 통계로 돌아오면 이전에 고른 달로 돌아온다. 연 통계 화면 사이를 옮길 때는 고른 해가 그대로다.

그래프는 E-01의 지출 상위 카테고리 가로 막대, E-02의 카테고리별 가로 막대, E-05의 월별 세로 막대만 둔다. 원 그래프는 쓰지 않는다. 그림에는 "막대 자리"로만 표시한다.

"이벤트 지출 제외" `[2]` 와 "할부: 구매한 달 / 청구 달" `[3]` 은 월별, 카테고리별, 연 단위 통계에만 둔다(F-305, F-306의 적용 화면). 할부 선택은 할부 거래가 있는 장부에서만 보인다.

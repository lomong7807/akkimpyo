## 2. 표기 규칙

화면 하나는 아래 순서로 적는다.

1. 제목: `### D-04 거래 입력·수정 [1]` (화면 ID, 이름, 단계. IA와 같다)
2. 들어오는 길: 어느 화면의 무엇을 눌러 오는지 한 줄
3. 휴대폰 폭 배치: 코드 블록 안의 글자 그림. 폭은 40자 안팎이다. 위아래 선만 긋고 오른쪽 세로선은 긋지 않는다(한글 폭 때문에 줄이 어긋난다).
4. 요소 표: `번호 | 요소 | 관련 기능`. 그림 안의 `(1)`, `(2)` 번호와 같다. 관련 기능에는 기능정의서의 F-ID를 적는다. 요소 설명은 한 줄을 넘기지 않는다.
5. 넓은 화면 배치: 휴대폰과 배치가 다를 때만 글자 그림을 하나 더 그린다. 같으면 "넓은 화면: 공통 틀 안에서 같은 배치"라고 한 줄만 적는다.
6. 뒤 단계 요소: 1단계 화면 안에 2단계나 3단계에 들어가는 요소는 요소 이름 뒤에 `[2]`, `[3]` 을 붙인다.

그림에 쓰는 기호는 다음과 같다.

| 기호 | 뜻 |
|------|----|
| `[ 글자 ]` | 버튼 |
| `[____]` | 입력란 |
| `( ) 글자` | 하나만 고르는 선택 |
| `[v] 글자` | 켜고 끄는 선택 |
| `글자 >` | 누르면 다른 화면으로 가는 줄 |
| `< 글자` | 뒤로 가기 |
| `...` | 같은 모양이 반복됨 |
| `(n)` | 요소 번호 |

요소 번호는 화면마다 1부터 다시 매긴다. 공통 틀의 요소는 번호를 매기지 않고 `{상단 바}`, `{하단 탭}`, `{사이드바}` 로만 적는다. 공통 틀의 내용은 이 문서 3절을 따른다.

## 3. 공통 틀 (B 그룹)

로그인 후의 모든 화면은 이 틀 안에 놓인다. 로그인 전 화면(A 그룹)과 첫 실행 안내(C-02), 열람 전용 화면(A-10)에는 이 틀이 없다.

### 3.1 휴대폰 폭

```
----------------------------------------
 (1) 내 가계부 v          (2) 3건  (3) !2
----------------------------------------

            화면 내용


                              (4) [ + ]
----------------------------------------
 (5) 홈   내역   통계   이벤트   더보기
----------------------------------------
```

| 번호 | 요소 | 화면 ID | 관련 기능 |
|------|------|---------|-----------|
| 1 | 장부 전환기 `[2]`. 현재 장부 이름. 누르면 장부 목록, "내 전체 지출", "장부 만들기"가 아래로 펼쳐진다. 1단계에는 장부 이름만 보이고 눌리지 않는다. | B-02 | F-803, F-821, F-802 |
| 2 | 동기화 상태 표시. 보내지 않은 입력이 있을 때만 건수가 보인다. 누르면 보내지 않은 입력 목록(B-05)으로 간다. 마지막으로 서버와 맞춘 시각은 B-05와 더보기 메뉴 맨 아래에 보인다. | B-04 | F-104, F-105, F-106 |
| 3 | 미확인 건수 배지 `[3]`. 미확인 거래가 있을 때만 보인다. 누르면 미확인 검토 목록(D-09)으로 간다. | B-06 | F-110 |
| 4 | 빠른 입력 버튼. 화면 오른쪽 아래에 떠 있다. 누르면 거래 입력(D-04)이 열린다. 입력 화면과 설정 화면에서는 보이지 않는다. | B-03 | F-102, F-103 |
| 5 | 주 내비게이션. 홈(C-01), 내역(D-01), 통계(E-01), 이벤트(F-01) `[2]`, 더보기(M-01). 1단계에는 이벤트 탭이 없어 네 칸이다. | B-01 | F-101 |

하위 화면(목록에서 들어간 상세, 입력, 설정)에서는 상단 바가 `< 뒤로   화면 이름   (화면별 버튼)` 으로 바뀌고 하단 탭은 그대로 보인다. 입력 화면(D-04, D-05, F-02, G-02, I-02, L-02, L-06)은 아래에서 올라오는 전체 화면이며 하단 탭과 빠른 입력 버튼이 보이지 않는다.

### 3.2 넓은 화면 (폭 1024 이상)

```
------------------------------------------------------------------------
 (1) 내 가계부 v     |
 (4) [ + 거래 입력 ] |
                     |
 (5) 홈              |              화면 내용
     내역            |
     통계            |      목록 화면은 가운데에 목록, 오른쪽에
     이벤트          |      고른 항목의 상세나 입력을 나란히 둔다
     ---             |
     계좌            |
     카테고리        |
     반복과 할부     |
     예산            |
     가져오기·내보내기|
     장부와 공유     |
     휴지통          |
     설정            |
                     |
 (3) 미확인 2건      |
 (2) 보내지 않은 3건 |
     10:42에 맞춤    |
------------------------------------------------------------------------
```

- 번호는 3.1과 같은 요소다. 하단 탭이 왼쪽 사이드바가 되고, 더보기 메뉴(M-01)의 항목이 사이드바에 펼쳐져 있다. 그래서 넓은 화면에서는 M-01 화면이 따로 없다.
- 폭 768 이상 1024 미만에서는 휴대폰 배치를 그대로 쓰되 내용 폭을 가운데로 제한한다.

### 3.3 보내지 않은 입력 목록 (B-05) `[1]`

들어오는 길: 상단 바의 동기화 상태 표시를 누른다.

```
----------------------------------------
 < 뒤로      보내지 않은 입력
----------------------------------------
 (1) 마지막으로 맞춘 시각 10:42
 (2) [ 지금 다시 보내기 ]
----------------------------------------
 (3) 대기 2건
     점심   식비   12,000원        (4) x
     커피   카페   4,500원             x
----------------------------------------
 (5) 보낼 수 없음 1건
     택시   교통   8,900원
     (6) 이유: 계좌가 삭제되었다
     (7) [ 고쳐서 보내기 ]  [ 버리기 ]
----------------------------------------
```

| 번호 | 요소 | 관련 기능 |
|------|------|-----------|
| 1 | 마지막으로 서버와 맞춘 시각 | F-104 |
| 2 | 지금 다시 보내기 버튼 | F-107 |
| 3 | 대기 중인 입력 목록 | F-106 |
| 4 | 대기 중인 입력 버리기 | F-109 |
| 5 | 보낼 수 없는 입력 목록 | F-106, F-108 |
| 6 | 서버가 거부한 이유 | F-106 |
| 7 | 고쳐서 보내기(거래 입력 화면을 연다), 버리기 | F-108, F-109 |

넓은 화면: 공통 틀 안에서 같은 배치.

## 4. 공통 배치 규칙

모든 화면이 따른다. 화면설계서와 구현에서도 같다.

1. 화면마다 주된 동작 버튼은 하나다. 입력 화면의 저장 버튼은 화면 맨 아래에 고정한다.
2. 입력란의 이름은 입력란 위에, 도움말은 입력란 바로 아래에, 오류 문구는 그 아래에 둔다. 입력란 안의 흐린 글자를 이름 대신 쓰지 않는다.
3. 되돌릴 수 없는 동작(완전히 지우기, 장부 삭제, 탈퇴, 내보내기)은 화면 맨 아래에 따로 떼어 놓고 확인 창을 거친다.
4. 금액은 줄의 오른쪽 끝에 맞춘다. 목록의 합계는 목록 위에 둔다.
5. 목록은 날짜로 묶고, 묶음마다 날짜와 그날 합계를 머리에 둔다.
6. 목록 화면에는 항목이 없을 때 보일 자리(무엇을 하면 채워지는지와 버튼 하나)를 목록 자리에 둔다. 그림은 항목이 있는 상태로 그린다.
7. 상자로 감싸는 것은 꼭 필요한 곳(확인 창, 고른 항목의 상세)에만 쓰고, 나머지는 선과 여백으로 나눈다.
8. 권한이 없어 쓸 수 없는 버튼은 숨기지 않고 흐리게 보여 주며 이유를 알려 준다. 보기 전용 구성원에게는 빠른 입력 버튼이 보이지 않는다.
9. 확인 창은 휴대폰에서는 아래에서 올라오는 판, 넓은 화면에서는 가운데 창이다.

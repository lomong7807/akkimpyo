# 와이어프레임: 로그인 전, 홈, 설정, 공통 상태 화면, 네이티브 전용

- 작성일: 2026-11-18
- 상태: 초안, 사용자 확인 전
- 근거 문서: [정보구조도](../02-information-architecture.md), [기능정의서](../03-feature-spec.md), [프로젝트 개요서](../01-project-overview.md), [페르소나와 사용 케이스](../01a-personas.md)
- 표기 규칙, 공통 틀, 공통 배치 규칙은 [00-common.md](00-common.md)를 따른다.
- 다루는 화면: A 로그인 전 10개, C 홈 2개, M 설정 6개, N 공통 상태 화면 4개, O 네이티브 전용 1개, 모두 23개.
- 그림 안의 사람 이름은 페르소나 문서에서 가져왔다. 혼자 쓰는 장부는 김도윤, 살림 장부는 이서연, 모임 장부는 정민서, 문자 자동 입력은 오세훈, 장부 두 개를 쓰는 경우는 한지우이다.

## 0. 이 문서에서 더한 표기

00-common.md 2절의 표기를 그대로 쓰고 다음 다섯 가지를 더한다.

1. 한 화면을 상태별로 나눠 그릴 때는 같은 요소에 같은 번호를 쓰고 요소 표는 하나로 합친다.
2. 공통 틀 안의 화면은 "공통 틀:" 줄에 상단 바의 형태, 하단 탭, 빠른 입력 버튼이 보이는지 적는다.
3. 그림 자리(앱 화면을 넣을 곳)는 위아래 `+----` 선과 왼쪽 `|` 선으로만 표시한다.
4. 오류 문구나 조건이 맞을 때만 뜨는 안내는 그리지 않고, 뜨는 자리를 요소 표에 적는다. 문구와 조건은 화면설계서에서 정한다.
5. 뒤로 가기처럼 기능정의서에 따로 없는 화면 이동은 관련 기능에 "없음(뒤로 가기)"로 적는다. 화면에 대응하는 F-ID 중 놓을 요소가 없는 것은 요소 표 아래에 "요소 없는 기능"으로 적는다.

## 1. A 로그인 전

A 그룹 화면에는 공통 틀이 없다(00-common.md 3절). 넓은 화면은 따로 그린 A-01, A-10을 빼고 휴대폰 배치를 화면 가운데에 좁은 폭으로 둔다.

### A-01 소개 페이지 `[출시]`

들어오는 길: 서비스 주소를 직접 열거나 검색 결과에서 들어온다. 로그인한 상태로 들어오면 홈(C-01)으로 바로 간다(F-001).

휴대폰 폭:

```

                        (3) [ 시작하기 ]
----------------------------------------
 (4) 어느 기기에서든 적으면 함께 쓰는
     사람과 같은 장부가 보이고, 여행이나
     데이트 지출은 기간만 정하면 따로
     묶여 보이는 가계부.
 (5) [ 시작하기 ]
 (6) +----------------------------------
     |  앱 화면 자리
     +----------------------------------
----------------------------------------
 (7) 기기 간 같은 데이터
 (8) 아이폰에서 적은 거래가 맥북에도
     바로 보인다. 연결이 없을 때 적은
     거래는 연결되면 보낸다.
 (9) +--------------  +-----------------
     |  휴대폰 화면   |  노트북 화면
     +--------------  +-----------------
----------------------------------------
 (10) +---------------------------------
      |  결제한 사람별 합계 화면
      +---------------------------------
 (11) 함께 쓰는 장부
 (12) 배우자나 모임 사람을 장부에
      초대한다. 거래마다 누가 결제했는지
      남는다.
----------------------------------------
 (13) 기간으로 묶는 이벤트
 (14) 제주 여행  10-09 ~ 10-12
      합계                     684,000원
      하루 평균                171,000원
      여행 빼고 10월 지출      561,300원
 (15) 기간만 정하면 그 사이 지출이
      따로 묶인다.
----------------------------------------
 (16) 이용약관 >
 (17) 개인정보 처리방침 >
----------------------------------------
```

| 2 | 로그인. 로그인(A-02)으로 간다 | F-001 |
| 3 | 시작하기 버튼. 가입(A-03)으로 간다. F-001의 "가입" 버튼이며 이 페이지에서는 이 이름만 쓴다 | F-001 |
| 4 | 한 문장 소개. 개요서 3절의 가치 제안 문장 | F-001 |
| 5 | 시작하기 버튼. (3)과 같다. 첫 화면의 버튼은 이것 하나다 | F-001 |
| 6 | 앱 화면 자리. 어느 화면을 넣을지는 화면설계서에서 정한다 | F-001 |
| 7 | 핵심 1의 제목: 기기 간 같은 데이터 | F-001 |
| 8 | 핵심 1의 설명 두세 줄. 그림의 문장은 예시다 | F-001 |
| 9 | 핵심 1의 그림 자리: 휴대폰과 노트북 화면을 나란히 | F-001 |
| 10 | 핵심 2의 그림 자리: 결제한 사람별 합계 화면 | F-001 |
| 11 | 핵심 2의 제목: 함께 쓰는 장부 | F-001 |
| 12 | 핵심 2의 설명 | F-001 |
| 13 | 핵심 3의 제목: 기간으로 묶는 이벤트 | F-001 |
| 14 | 핵심 3의 예시 숫자. 그림 대신 이벤트 합계, 하루 평균, 이벤트를 뺀 달 지출을 글자로 보인다 | F-001 |

| 16 | 이용약관(A-08)으로 가는 줄 | F-021 |

```
      |  결제한 사람별 합계 화면         (12) 배우자나 모임 사람을 장부에

----------------------------------------------------------------------------

 (14) 제주 여행  10-09 ~ 10-12
      합계                     하루 평균                 여행 빼고 10월 지출
      684,000원                171,000원                 561,300원
 (15) 기간만 정하면 그 사이 지출이 따로 묶인다.
----------------------------------------------------------------------------
```

- 첫 화면은 소개 문장과 버튼을 가운데에 두고 앱 화면 자리를 그 아래 전체 폭으로 둔다.
- 핵심 1은 왼쪽 글, 오른쪽 그림. 핵심 2는 왼쪽 그림, 오른쪽 글. 핵심 3은 예시 숫자 세 개를 가로로 늘어놓는다.

### A-02 로그인 `[1]`

들어오는 길: 소개 페이지(A-01)의 로그인 `[출시]`, 로그인이 필요한 주소를 로그인 없이 열었을 때(F-011), 초대 링크 화면(A-07)의 로그인 `[2]`, 로그아웃한 뒤(F-016).

```
----------------------------------------
 (1) 로그인
----------------------------------------
 (2) 이메일
     [doyun.kim@example.com___________]
 (3) 비밀번호
     [________________________________]
 (4) [ 로그인 ]
----------------------------------------
```

| 번호 | 요소 | 관련 기능 |
|------|------|-----------|
| 1 | 화면 이름 | F-009 |
| 2 | 이메일 입력란 | F-009 |
| 3 | 비밀번호 입력란 | F-009 |
| 4 | 로그인 버튼. 로그인 실패 문구와 잠금 안내 `[출시]` 는 이 버튼 바로 위에 뜬다 | F-009, F-010 |

요소 없는 기능:
- F-011 (로그인 전에 가려던 주소를 기억했다가 로그인 뒤 그 주소로 보내는 동작이다)
- F-019 (탈퇴 유예 중인 계정이 로그인하면 서버가 탈퇴를 취소하는 동작이다. "탈퇴 신청이 취소되었다"는 한 번 뜨는 짧은 알림이며 띄울 곳은 화면설계서에서 정한다)

가입(A-03)과 비밀번호 재설정 요청(A-05)으로 가는 링크는 기능정의서와 IA 내비게이션에 없어 그리지 않았다(7절 빈틈 2).

넓은 화면: 같은 배치를 화면 가운데에 둔다.

### A-03 가입 `[1]`

들어오는 길: 소개 페이지(A-01)의 시작하기 `[출시]`, 초대 링크 화면(A-07)의 가입 `[2]`. 1단계에는 들어오는 길이 정의되어 있지 않다(7절 빈틈 2).

```
----------------------------------------
 (1) < 뒤로      가입
----------------------------------------
 (2) 이메일
     [doyun.kim@example.com___________]
 (3) 비밀번호
     [________________________________]
     8자 이상, 영문과 숫자를 함께 쓴다
 (4) 비밀번호 확인
     [________________________________]
 (5) 표시 이름
     [김도윤__________________________]
     장부를 함께 쓰는 사람에게 보인다
----------------------------------------
 (6) 약관 동의 [출시]
     [v] 모두 동의
     [v] 이용약관 동의(필수)      보기 >
     [v] 개인정보 처리방침 동의(필수)
                                  보기 >
----------------------------------------
 (7) [ 가입 ]
----------------------------------------
```

| 번호 | 요소 | 관련 기능 |
|------|------|-----------|
| 1 | 뒤로 가기 | 없음(뒤로 가기) |
| 2 | 이메일 입력란. 이미 가입된 이메일, 허용 목록 밖 이메일 `[1]` 의 오류는 이 아래에 뜬다 | F-002, F-003 |
| 3 | 비밀번호 입력란과 도움말 | F-002 |
| 4 | 비밀번호 확인 입력란 | F-002 |
| 5 | 표시 이름 입력란과 도움말 | F-002 |
| 6 | 약관 동의 `[출시]`. 모두 동의, 필수 두 항목, 항목별 보기(A-08, A-09) | F-004 |
| 7 | 가입 버튼. 화면 맨 아래 고정. 요청 횟수 초과 안내 `[출시]` 는 이 버튼 바로 위에 뜬다 | F-002, F-004, F-005 |

- 1단계 가입 화면에는 (6) 약관 동의 묶음이 없다. 약관 동의는 `[출시]` 에 들어간다(F-004, P-112). `[출시]` 에는 필수 두 항목에 모두 동의해야 (7)이 눌린다.
- 1단계에는 허용 목록에 있는 이메일만 가입한다(F-003, P-102).

넓은 화면: 같은 배치를 화면 가운데에 둔다.

### A-04 이메일 인증 안내·완료 `[출시]`

들어오는 길: 가입(A-03)을 마친 직후와 인증하지 않은 계정으로 로그인했을 때(F-009)는 인증 안내가, 메일의 인증 링크를 열면 인증 완료가 나온다.

```
 (4) [ 인증 메일 다시 보내기 (42초) ]
----------------------------------------
```

인증 완료:

```
----------------------------------------
 (1) 이메일 인증
----------------------------------------
 (5) 인증이 끝났다.
 (6) [ 로그인 ]
----------------------------------------
```

| 번호 | 요소 | 관련 기능 |
|------|------|-----------|
| 1 | 화면 이름 | F-006, F-007 |
| 2 | 인증 메일을 보낸 주소 | F-006 |
| 3 | 인증 방법 안내 | F-006 |
| 4 | 인증 메일 다시 보내기. 1분에 한 번 되며 남은 초를 버튼에 보인다 | F-006 |
| 5 | 인증 결과 문구. 링크를 쓸 수 없거나 이미 인증된 경우의 문구도 이 자리에 온다 | F-007 |
| 6 | 로그인 버튼(A-02). 링크를 쓸 수 없으면 이 자리에 인증 메일 다시 보내기가 온다 | F-007 |

인증 안내 화면에서 다른 곳으로 가는 길이 없다(7절 빈틈 3).

넓은 화면: 같은 배치를 화면 가운데에 둔다.

넓은 화면: 공통 틀 안에서 같은 배치.

### N-03 서버 오류·연결 없음 안내 `[1]`

들어오는 길: 서버가 응답하지 않거나 오류를 돌려주면 서버 오류 화면이, 연결이 끊기면 지금 화면 위에 연결 없음 띠가 나온다.

공통 틀: 상단 바(기본 형태), 하단 탭, 빠른 입력 버튼이 보인다. 연결이 없어도 새 거래 입력은 되므로 빠른 입력 버튼은 그대로 둔다(F-102, F-103).

서버 오류:

```
----------------------------------------
 {상단 바}
----------------------------------------

 (1) 잠시 문제가 생겼다.
 (2) [ 다시 시도 ]
 (3) 마지막으로 맞춘 시각 10:42

----------------------------------------
 {하단 탭}
----------------------------------------
```

연결 없음(홈 위에 뜬 경우):

```
----------------------------------------
 {상단 바}
----------------------------------------
 (4) 연결 없음. 새 거래 입력만 할 수
     있고 수정과 삭제는 연결되면 할 수
     있다.
----------------------------------------
     (아래는 홈 C-01의 내용이다)
     11월 합계  (5) 10:42 기준
     지출                    1,245,300원
     ...
----------------------------------------
 {하단 탭}
----------------------------------------
```

| 번호 | 요소 | 관련 기능 |
|------|------|-----------|
| 1 | 오류 안내 문장 | F-907 |
| 2 | 다시 시도 | F-907 |
| 3 | 마지막으로 맞춘 시각. 같은 오류가 되풀이될 때만 보인다 | F-907 |
| 4 | 연결 없음 띠. 모든 화면의 상단 바 바로 아래에 뜨고 연결이 돌아오면 사라진다 | F-908 |
| 5 | 기준 시각. 잔액과 합계 옆에 붙어 마지막으로 맞춘 시각의 값임을 알린다 | F-908 |

- 입력 화면에서 저장 중 서버 오류가 나면 이 화면으로 바꾸지 않는다. 입력한 내용을 그대로 두고 저장 버튼 위에 오류 문구와 다시 시도를 보인다(F-907, P-904).
- 연결 없음 띠 아래의 내용은 홈, 내역, 달력, 계좌 목록, 카테고리 목록이면 기기에 저장한 데이터로 읽기 전용으로 보인다(F-908).

넓은 화면: 공통 틀 안에서 같은 배치. 연결 없음 띠는 내용 영역 맨 위에 전체 폭으로 둔다.

### N-04 수정 충돌 안내 `[1]`

들어오는 길: 다른 기기에서 먼저 고친 거래를 저장하거나 바꾸려 할 때(F-909, P-217).

공통 틀: 저장하거나 동작한 화면(거래 입력·수정 D-04, 거래 상세 D-06 등) 위에 뜨는 확인 창이다. 휴대폰에서는 아래에서 올라오는 판이다(공통 배치 규칙 9).

수정을 저장하다 충돌한 때:

```
----------------------------------------
 (1) 다른 기기에서 먼저 고쳤다
----------------------------------------
 (2)           최신 내용     내 입력
     금액      12,000원      13,000원
     메모      팀 점심       (없음)
----------------------------------------
 (3) [ 내 입력 다시 적용 ]
 (4) [ 최신 내용 보기 ]
----------------------------------------
```

승인취소, 삭제 같은 다른 동작이 충돌한 때:

```
----------------------------------------
 (1) 다른 기기에서 먼저 고쳤다
----------------------------------------
 (5) 11월 18일 12:10  고기국수집
     식비  신한카드             12,000원
 (6) 그래도 삭제할까?
----------------------------------------
 (7) [ 다시 하기 ]
 (8) [ 그만두기 ]
----------------------------------------
```

| 번호 | 요소 | 관련 기능 |
|------|------|-----------|
| 1 | 제목 | F-909 |
| 2 | 최신 내용과 내 입력을 항목별로 나란히 | F-909 |
| 3 | 내 입력 다시 적용. 최신 내용 위에 내가 바꾼 항목을 얹은 수정 화면(D-04)을 연다. 주된 버튼 | F-909 |
| 4 | 최신 내용 보기. 내 입력을 버리고 거래 상세(D-06)를 연다 | F-909 |
| 5 | 최신 거래 내용 | F-909 |
| 6 | 다시 할지 묻는 문장. 하려던 동작의 이름(삭제, 승인취소 등)이 들어간다 | F-909 |
| 7 | 다시 하기. 주된 버튼 | F-909 |
| 8 | 그만두기 | F-909 |

넓은 화면: 같은 배치를 가운데 창으로 둔다(공통 배치 규칙 9).

## 7. 발견한 빈틈

화면을 그리다가 찾은 것이다. 기능정의서나 IA에 정의가 없어 그리지 않았거나, 문서끼리 어긋나 한쪽을 따른 것이다. 사용자 확인이 필요하다.

| 번호 | 빈틈 | 관련 화면 | 이 문서에서 한 것 |
|------|------|-----------|-------------------|
| 1 | 서비스 이름이 어느 문서에도 없다. 소개 페이지 상단과 홈 화면 설치(F-120)의 앱 이름에 필요하다. | A-01 | "서비스 이름"으로 자리만 두었다. |
| 2 | 로그인에서 가입(A-03)과 비밀번호 재설정 요청(A-05)으로 가는 링크가 없다. A-02의 기능(F-009, F-010, F-011, F-019)과 IA 3절 내비게이션 어디에도 없다. F-002와 F-010의 오류 문구는 재설정을 권하므로 링크가 있어야 한다. 특히 1단계에는 소개 페이지(A-01)가 `[출시]`, 초대 링크 화면(A-07)이 `[2]` 라서 가입 화면으로 들어오는 길이 하나도 없다. | A-02, A-03, A-05 | 그리지 않았다. |
| 3 | 이메일 인증 안내에서 나갈 길이 없다. F-006은 다시 보내기만 정했다. 이메일을 잘못 적고 가입한 사람은 이메일을 바꿀 수 없으므로(P-113) 로그인이나 가입으로 가는 길이 필요하다. | A-04 | 그리지 않았다. |
| 4 | 회원 탈퇴 완료 화면에서 어디로 가는지 정의가 없다. F-018은 완료 화면을 보여 준다고만 정했다. 모든 기기가 로그아웃되므로 로그인(A-02)이나 소개 페이지(A-01) 중 하나를 정해야 한다. | M-05 | 완료 화면에 버튼을 그리지 않았다. |
| 5 | 접근 권한 없음에서 "권한이 모자란 동작"일 때 둘 버튼이 없다. F-906의 "다른 장부로 이동"은 장부를 볼 수 없는 경우에만 정의되어 있다. | N-02 | 그 경우의 버튼은 그리지 않았다. |
| 6 | 넓은 화면 사이드바(00-common.md 3.2)의 "반복과 할부", "가져오기·내보내기", "설정"이 가리킬 화면이 IA에 없다. F-901은 I-01과 I-03, K-01과 K-02와 K-05, M-02~M-06을 각각 따로 가는 목록으로 정했다. 넓은 화면에는 M-01이 없으므로 묶음 화면을 둘지, 사이드바 안에서 펼칠지 정해야 한다. 이용약관(A-08), 개인정보 처리방침(A-09), 회원 탈퇴(M-05)도 사이드바에 자리가 없다. | M-01 | 휴대폰 폭 M-01은 F-901대로 화면마다 줄을 따로 두었다. |
| 7 | 빠른 입력 버튼이 보이는 범위가 다르다. F-102는 로그인 뒤 모든 화면(보기 전용 장부 제외)이고, 00-common.md 3.1은 입력 화면과 설정 화면에서 숨긴다. 어느 화면이 "설정 화면"인지도 정해져 있지 않다. | M-01~M-05, N 그룹 | 00-common.md를 따라 M-02~M-05에서 숨기고, M-01과 N-01~N-03에서는 보였다. |
| 8 | 동기화 상태 표시의 범위가 다르다. F-104는 모든 화면에 "보내지 않은 입력 N건"과 마지막으로 맞춘 시각을 보이고 0건이면 시각만 보인다고 정했다. 00-common.md 3.1은 휴대폰 상단 바에 건수만 두고 시각은 B-05와 더보기 메뉴 맨 아래에 둔다. | M-01 | 00-common.md를 따라 M-01 맨 아래에 시각을 두었다. |

| 10 | 가입으로 가는 버튼의 이름이 화면마다 다르다. A-01은 "시작하기"(F-001은 "가입"), A-07은 F-816대로 "가입"이다. | A-01, A-07 | 문구를 하나로 맞출지 화면설계서에서 정한다. |

# 와이어프레임: 계좌, 카테고리, 반복과 할부, 예산, 가져오기와 내보내기, 장부와 공유

- 작성일: 2026-11-18
- 상태: 초안, 사용자 확인 전
- 근거 문서: [정보구조도](../02-information-architecture.md), [기능정의서](../03-feature-spec.md), [페르소나와 사용 케이스](../01a-personas.md)
- 표기, 공통 틀, 공통 배치 규칙은 [00-common.md](00-common.md)를 따른다.

## 읽기 전에

- 이 문서는 G 계좌, H 카테고리, I 반복과 할부, J 예산, K 가져오기와 내보내기, L 장부와 공유 그룹의 화면 22개를 그린다.
- 이 문서의 화면은 모두 하위 화면이라 상단 바가 `< 뒤로   화면 이름   (화면별 버튼)` 이다. 화면별 버튼에만 번호를 매긴다. 입력 화면(G-02, I-02, L-02, L-06)에는 하단 탭이 없다.
- 한 화면을 상태별로 나눠 그린 경우 "그림 가", "그림 나"로 나눈다. 요소 번호는 그 화면 안에서 이어서 매기고, 여러 그림에 같은 요소가 나오면 같은 번호를 쓴다. 요소 표는 화면마다 하나다.
- 확인 창은 문구와 확인, 취소 버튼 말고 다른 요소(고르기, 입력란, 건수, 다른 버튼)가 있을 때만 그린다. 그 밖의 확인 창은 요소 표에 "확인 창을 거친다"로만 적고, 문구는 화면설계서에서 정한다.
- 하나만 고르는 선택(`( )`)은 고른 상태를 그림에 표시하지 않고, 그림이 무엇을 고른 상태인지 요소 표에 적는다.
- 그림 속 예시: L 그룹은 정민서(P4)가 소유자인 "여행 모임 회비" 장부를 쓰고, 그 장부에 보기 전용으로 들어온 이서연(P2)의 눈으로 본 그림을 함께 둔다. 엑셀 가져오기는 장영숙(P8)이 엑셀로 쓰던 가계부를 옮기는 경우, 내보내기는 한지우(P5)가 사업 경비 장부를 내보내는 경우다.

## G. 계좌

### G-01 계좌 목록 [1]

들어오는 길: 더보기(M-01)의 "계좌"를 누른다. 홈(C-01)의 계좌 잔액 요약을 눌러도 온다.

휴대폰 폭:

```
----------------------------------------
 < 뒤로      계좌           (1) [ 추가 ]
----------------------------------------
 (2) 자산 합계               6,325,800원
----------------------------------------
 (3) 은행                    6,853,200원
 (4) 국민은행 급여통장       3,210,000원
     카카오뱅크 생활비       2,643,200원
     토스뱅크 비상금         1,000,000원
----------------------------------------
     카드                     -612,400원
     신한카드                 -482,300원
     현대카드                 -130,100원
----------------------------------------
     현금                       85,000원
     현금                       85,000원
----------------------------------------
 (5) 숨긴 계좌 1개 v
 (6) 우리은행 예전통장               0원
     (7) [ 다시 보이기 ]
----------------------------------------
 {하단 탭}
----------------------------------------
```

| 번호 | 요소 | 관련 기능 |
|------|------|-----------|
| 1 | 계좌 추가 버튼. 계좌 추가(G-02)를 연다. 편집 이상이며 보기 전용에게는 흐리게 보인다. | F-501, F-502 |
| 2 | 자산 합계. 모든 계좌 잔액의 합이며 카드의 음수 잔액과 숨긴 계좌의 잔액을 넣는다. | F-501 |
| 3 | 묶음 머리. 은행, 카드, 현금 순으로 종류 이름과 묶음 합계를 둔다. | F-501 |
| 4 | 계좌 줄. 이름과 잔액. 카드의 음수 잔액은 갚을 금액이다. 누르면 계좌 상세(G-03)로 간다. | F-501, F-505 |
| 5 | 숨긴 계좌 묶음. "숨긴 계좌 N개"를 눌러 펼친다. 그림은 펼친 상태다. | F-501 |
| 6 | 숨긴 계좌 줄. 이름과 잔액. 누르면 계좌 상세(G-03)로 간다. | F-501, F-505 |
| 7 | 다시 보이기 버튼. 입력할 때 계좌 선택 목록에 다시 나온다. 편집 이상. | F-507 |

넓은 화면: 공통 틀 3.2에 따라 가운데에 계좌 목록, 오른쪽에 고른 계좌의 상세(G-03)를 둔다.

```
--------------------------------------------------------------------------------------
 {사이드바} | 계좌                 (1) [ 추가 ] | (G-03 계좌 상세)
            |-----------------------------------| 고른 계좌의 상세가 이 자리에 열린다.
            | (2) 자산 합계         6,325,800원 | 배치와 번호는 G-03 그림을 따른다.
            |-----------------------------------|
            | (3) 은행              6,853,200원 |
            | (4) 국민은행 급여통장 3,210,000원 |
            |     카카오뱅크 생활비 2,643,200원 |
            |     토스뱅크 비상금   1,000,000원 |
            |-----------------------------------|
            |     카드               -612,400원 |
            |     ...                           |
            |-----------------------------------|
            | (5) 숨긴 계좌 1개 v               |
--------------------------------------------------------------------------------------
```

요소 없는 기능: F-908 (연결이 없을 때의 읽기 전용 표시, 안내 띠, 잔액 옆 마지막으로 맞춘 시각이다. 연결 없음 상태에서만 보이므로 화면설계서의 예외 상태에서 다룬다.)

### G-02 계좌 추가·수정 [1]

들어오는 길: 계좌 목록(G-01)의 "추가"를 누르면 추가로, 계좌 상세(G-03)의 "수정"을 누르면 수정으로 열린다.

휴대폰 폭(수정할 때. 추가할 때는 제목이 "계좌 추가"이고 5가 없다):

```
----------------------------------------
 < 뒤로      계좌 수정
----------------------------------------
 (1) 이름
     [신한카드____________]
     1~50자
 (2) 종류
     ( ) 은행   ( ) 카드   ( ) 현금
 (3) 지금 갚을 금액
     [350,000_____________] 원
     카드는 지금 갚을 금액을 적는다
 (4) 기준일
     [2026-10-01__________]
 (5) 시작 잔액이나 기준일을 바꾸면
     잔액을 다시 계산한다
----------------------------------------
 (6) 카드 식별 문구
     신한카드                          x
     1234                              x
     [______________]  [ 추가 ]
     (7) 문자 자동 입력이 이 문구로
     계좌를 찾는다. 최대 5개, 각 1~20자
----------------------------------------
 (8) [ 저장 ]
----------------------------------------
```

| 번호 | 요소 | 관련 기능 |
|------|------|-----------|
| 1 | 이름 입력란. 1~50자이며 같은 장부 안에서 겹칠 수 없다. | F-502, F-503 |
| 2 | 종류 선택. 은행, 카드, 현금. 그림은 카드를 고른 상태다. 할부 거래가 있는 카드는 수정할 때 종류를 바꿀 수 없다. | F-502, F-503 |
| 3 | 시작 잔액 입력란. 은행과 현금은 이름이 "시작 잔액"이고 음수도 받는다. 카드는 이름이 "지금 갚을 금액"이고 양수로 받아 음수로 저장한다. | F-502, F-503 |
| 4 | 기준일 입력란. 기본값은 오늘이다. | F-502, F-503 |
| 5 | 다시 계산 안내. 수정할 때만 기준일 입력란 아래에 보인다. | F-503 |
| 6 | 카드 식별 문구 `[3]`. 카드일 때만 보인다. 등록한 문구 목록과 지우기(x), 새 문구 입력란과 추가 버튼. | F-504 |
| 7 | 식별 문구 도움말. 문자 자동 입력이 이 문구로 계좌를 찾는다는 것과 개수, 글자 수 제한. | F-504 |
| 8 | 저장 버튼. 화면 맨 아래에 고정한다. | F-502, F-503 |

넓은 화면: G-01 넓은 화면의 오른쪽 영역에 열리고 배치는 휴대폰과 같다.

### G-03 계좌 상세 [1]

들어오는 길: 계좌 목록(G-01)에서 계좌 줄이나 숨긴 계좌 줄을 누른다.

휴대폰 폭, 그림 가: 거래가 없는 계좌(삭제할 수 있다)

```
----------------------------------------
 < 뒤로      계좌 상세      (1) [ 수정 ]
----------------------------------------
 (2) 토스뱅크 비상금
     은행
 (3) 현재 잔액               1,000,000원
 (4) 시작 잔액 1,000,000원
     기준일 2026-11-18
----------------------------------------
 (5) <       2026년 11월       >
----------------------------------------
 (6) 거래가 없을 때 보일 자리



----------------------------------------
 (7) [ 숨기기 ]
----------------------------------------
 (8) [ 계좌 삭제 ]
----------------------------------------
 {하단 탭}
----------------------------------------
```

휴대폰 폭, 그림 나: 거래가 있는 계좌(숨기기만 된다)

```
----------------------------------------
 < 뒤로      계좌 상세      (1) [ 수정 ]
----------------------------------------
 (2) 카카오뱅크 생활비
     은행
 (3) 현재 잔액               2,643,200원
 (4) 시작 잔액 2,500,000원
     기준일 2026-11-05
----------------------------------------
 (5) <       2026년 11월       >
----------------------------------------
 (9) 11월 17일 화요일           -6,800원
     GS25 역삼점  식비          -6,800원
----------------------------------------
     11월 12일 목요일         +500,000원
     국민은행 급여통장에서    +500,000원
----------------------------------------
     11월 10일 화요일         -350,000원
     신한카드로               -350,000원
----------------------------------------
     11월 3일 화요일           -23,000원
     다이소  생활용품          -23,000원
     (10) 잔액에 반영 안 됨
----------------------------------------
 (7) [ 숨기기 ]
----------------------------------------
 (11) 거래가 있는 계좌는 숨기기만 된다
----------------------------------------
 {하단 탭}
----------------------------------------
```

| 번호 | 요소 | 관련 기능 |
|------|------|-----------|
| 1 | 수정 버튼. 값을 채운 계좌 수정(G-02)을 연다. 편집 이상. | F-503 |
| 2 | 계좌 이름과 종류 | F-505 |
| 3 | 현재 잔액. 카드는 음수(갚을 금액)로 보인다. | F-505 |
| 4 | 시작 잔액과 기준일 | F-505 |
| 5 | 월 이동. 이전 달과 다음 달로 옮긴다. | F-505 |
| 6 | 거래가 없을 때 보일 자리. 문구와 버튼은 화면설계서에서 정한다(공통 배치 규칙 6). | F-505 |
| 7 | 숨기기 버튼. 확인 창을 거쳐 숨긴다. 숨긴 계좌이면 같은 자리에 "다시 보이기"가 보인다. 편집 이상. | F-506, F-507 |
| 8 | 계좌 삭제 버튼. 휴지통을 포함해 거래가 하나도 없을 때만 보이고 확인 창을 거친다. 편집 이상. | F-508 |
| 9 | 그 달의 거래 목록. 날짜로 묶고 머리에 그날 합계를 둔다. 이체는 상대 계좌 이름을 보인다. 줄을 누르면 거래 상세(D-06)로 간다. | F-505 |
| 10 | 기준일 이전 거래 표시. 이 거래는 통계에는 들어가고 잔액에는 반영되지 않는다. | F-505 |
| 11 | 삭제할 수 없는 이유. 거래가 있으면 8 대신 보인다. 이 계좌를 쓰는 반복 거래 `[3]` 가 있으면 "반복 거래에서 계좌를 바꾼 뒤 삭제하라"가 보인다. | F-508 |

넓은 화면: G-01 넓은 화면 그림의 오른쪽 영역에 놓이고 배치는 휴대폰과 같다.

## H. 카테고리

### H-01 카테고리 관리 [1]

들어오는 길: 더보기(M-01)의 "카테고리"를 누른다.

휴대폰 폭, 그림 가: 목록

```
----------------------------------------
 < 뒤로      카테고리       (1) [ 추가 ]
----------------------------------------
 (2) ( ) 지출   ( ) 수입
----------------------------------------
 (3) 식비
 (4)   - 외식
       - 장보기
     카페·간식
     교통
     주거·통신
     ...
     기타
----------------------------------------
 (5) 미분류       (6) 기본, 고칠 수 없음
----------------------------------------
 {하단 탭}
----------------------------------------
```

휴대폰 폭, 그림 나: 추가·이름 바꾸기 판(아래에서 올라온다. 그림은 두 경우의 요소를 함께 그렸다)

```
----------------------------------------
 (7) 카테고리 추가
----------------------------------------
 (8) 구분: 지출
 (9) 이름
     [외식________________]
     1~20자
 (10) 상위 카테고리
     [ 식비 v ]
----------------------------------------
 (11) [ 저장 ]
----------------------------------------
 (12) [ 삭제 ]
----------------------------------------
```

휴대폰 폭, 그림 다: 삭제 확인 창(옮길 카테고리 고르기)

```
----------------------------------------
 (13) '식비'를 삭제한다
----------------------------------------
 (14) 거래 128건을 다른 카테고리로
      옮긴다(하위와 휴지통 포함)
 (15) 하위 2개(외식, 장보기)도 함께
      삭제된다
 (16) 거래를 옮길 카테고리
      [ 미분류 v ]
----------------------------------------
 (17) [ 삭제 ]   [ 취소 ]
----------------------------------------
```

| 번호 | 요소 | 관련 기능 |
|------|------|-----------|
| 1 | 추가 버튼. 그림 나의 판을 "카테고리 추가"로 연다. 편집 이상. | F-510 |
| 2 | 지출과 수입 전환. 그림은 지출을 고른 상태다. | F-509 |
| 3 | 최상위 카테고리 줄. 누르면 그림 나의 판을 "이름 바꾸기"로 연다. | F-509, F-511 |
| 4 | 하위 카테고리 줄. 상위 아래에 들여 써서 보인다. 누르면 3과 같다. | F-509, F-511 |
| 5 | 미분류 줄. 목록 맨 아래에 고정한다. 눌러도 판이 열리지 않는다. | F-509 |
| 6 | "기본" 표시와 고칠 수 없다는 표시. 미분류에는 이름 바꾸기와 삭제가 없다. | F-509, F-511, F-512 |
| 7 | 판 제목. 추가 버튼으로 열면 "카테고리 추가", 줄을 눌러 열면 "이름 바꾸기"다. | F-510, F-511 |
| 8 | 구분. 그림 가에서 고른 쪽이며 판에서는 바꾸지 않는다. | F-510 |
| 9 | 이름 입력란. 1~20자이며 같은 상위 아래에서 겹칠 수 없다. | F-510, F-511 |
| 10 | 상위 카테고리 선택. 추가할 때만 보인다. "없음"(최상위로 만들기) 또는 같은 구분의 최상위 하나(미분류 제외). | F-510 |
| 11 | 저장 버튼 | F-510, F-511 |
| 12 | 삭제 버튼. 이름 바꾸기로 열었을 때만 판 맨 아래에 보인다. 누르면 그림 다의 확인 창이 열린다. | F-512 |
| 13 | 확인 창 제목. 삭제할 카테고리 이름이 들어간다. | F-512 |
| 14 | 옮겨지는 거래 수. 하위와 휴지통의 거래를 넣어 센다. | F-512 |
| 15 | 하위도 함께 삭제된다는 안내. 하위가 있을 때만 보인다. | F-512 |
| 16 | 거래를 옮길 카테고리 선택. 기본값은 같은 구분의 미분류다. 삭제 대상과 그 하위는 고를 수 없다. | F-512 |
| 17 | 삭제와 취소 버튼 | F-512 |

넓은 화면: 공통 틀 안에서 목록 배치는 같다. 그림 나의 판은 목록 오른쪽에 나란히 열리고(공통 틀 3.2), 그림 다의 확인 창은 가운데 창이다(공통 배치 규칙 9).

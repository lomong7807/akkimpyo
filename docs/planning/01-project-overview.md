# 가계부 앱 프로젝트 개요서

- 작성일: 2026-11-18
- 상태: 초안, 사용자 확인 전
- 근거 문서: [설계 문서](../superpowers/specs/2026-11-18-account-book-design.md)
- 표기: `[사용자]` 사용자가 직접 정함, `[제안]` 설계자가 제안했고 사용자 확인 전, `[사실]` 조사로 확인

## 1. 기획 배경

발견한 문제는 다음 세 가지이다. 출처는 설계 문서 1.2절과 2.3절이다. `[사실]`

1. 아이폰과 Mac/PC를 함께 쓸 수 있는 국내 가계부가 적다. 그중 편한가계부는 실시간 동기화가 유료 구독에서만 된다.
2. 여러 사람이 같은 장부를 쓰는 기능이 국내 앱에 사실상 없다. 뱅크샐러드 '우리집돈관리'는 2025-07-31에 종료되었다. 남은 방법은 한 계정을 같이 쓰는 것인데 "배우자 내꺼 구분이 자동으로 안돼서" 불편하다는 후기가 있다.
3. 여행·데이트처럼 기간이 있는 지출을 따로 보려면 날짜 필터로 모아 태그를 달거나 "여행비 빼면 이번 달 얼마"를 손으로 계산해야 한다.

추가로, 국내 앱 이탈 이유 1순위는 수기 입력의 번거로움이다. `[사실]`

만드는 이유는 다음과 같다. 맥북과 아이폰 어느 쪽에서 입력해도 서로 보이고, 혼자도 함께도 쓰는 가계부를 공개 출시한다. `[사용자]`

## 2. 타겟 사용자

두 명의 페르소나는 모두 `[제안]`이다.

| 구분 | 김도윤 (33세, 직장인, 혼자 씀) | 이서연 (31세, 맞벌이 신혼) |
|------|------|------|
| 상황 | 회사에서는 맥북, 밖에서는 아이폰을 쓴다. | 배우자와 한 계정에 같이 로그인해 살림 가계부를 쓴다. |
| 행동 패턴 | 결제 직후 적으려다 미루고, 주말에 카드 내역을 보며 몰아서 입력한다. 가계부 앱을 두 번 쓰다 그만뒀다. 여행을 다녀온 달은 여행비를 뺀 평소 지출을 손으로 계산한다. | 데이트 비용과 친구 모임 회비는 따로 엑셀로 관리한다. |
| 페인 포인트 | 입력이 귀찮다. 기기 간 동기화가 유료다. 여행 지출이 월 통계를 흐린다. | 누가 쓴 지출인지 구분되지 않는다. 살림·모임·개인 지출이 한 장부에 섞인다. 내 지출만 따로 보기 어렵다. |

## 3. 핵심 가치 제안 `[제안]`

"어느 기기에서든 적으면 함께 쓰는 사람과 같은 장부가 보이고, 여행이나 데이트 지출은 기간만 정하면 따로 묶여 보이는 가계부."

## 4. 핵심 지표

측정 시작은 공개 출시일이다. 모든 항목은 `[제안]`이다.

| 지표 | 측정 방법 | 목표선 |
|------|-----------|--------|
| 4주 유지율 | 가입 후 22~28일째에 거래를 1건 이상 기록한 가입자 비율 | 30% 이상 |
| 입력 시간 | 입력 화면을 연 때부터 저장까지 걸린 시간의 중앙값(수기 입력) | 10초 이하 |
| 주간 기록 일수 | 주간 활성 사용자가 한 주에 거래를 기록한 날 수의 중앙값 | 4일 이상 |
| 공유 사용률 | 가입 4주 안에 구성원 2명 이상인 장부에 속한 가입자 비율 | 20% 이상 |
| 이벤트 사용률 | 월간 활성 사용자 중 이벤트를 1개 이상 만든 비율 | 15% 이상 |
| 데이터 불일치 신고 | 입력이 사라졌거나 기기마다 다르게 보인다는 신고 건수 | 월 0건 |

목표선은 근거 자료 없이 정한 초기 값이며 공개 후 첫 4주 실측으로 다시 정한다.

## 5. 범위 요약

- 대상: 웹, macOS, iOS. 안드로이드는 제외한다. `[사용자]`
- 순서: 웹앱을 먼저 만들고 SwiftUI 네이티브 앱은 나중에 추가한다. `[사용자]`
- 출시 범위에 넣지 않는 것: 은행·카드 직접 연동, 정산 계산, 영수증 인식, 다중 통화. 출시 후 하나씩 추가한다. `[사용자]`
- 미결: 공개 시점, 유료화 여부, 회원 탈퇴 시 데이터 처리, 호스팅 위치, 비로그인 범위. `[사용자 결정 필요]`
